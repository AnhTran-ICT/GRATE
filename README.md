# GRATE - Game Rating Platform

## Overview

GRATE (Game Rating Platform) is a community-driven game review platform that allows users to discover games, view ratings, submit reviews, and report inappropriate content.

The platform provides a structured review system with moderation features to maintain review quality and user trust.
